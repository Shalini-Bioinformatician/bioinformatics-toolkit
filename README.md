# 🧬 Bioinformatics Toolkit

A growing collection of practical Python and Bash tools for common bioinformatics data analysis tasks.

## 🎯 Purpose

This repository documents my hands-on bioinformatics programming practice. Each tool is developed while learning to work with real biological data formats and solve common data analysis problems.

The goal is to build small, reusable, and well-documented tools rather than simply collecting code.

## 🛠️ Tools and Technologies

- Python
- Bash
- Linux
- Biopython
- Pandas
- NumPy
